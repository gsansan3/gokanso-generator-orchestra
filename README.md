# ご感想ジェネレータ ～オーケストラ版～

演奏会のアンケートの自由記述欄に書かれていそうな「ご感想」を、スロットのようにランダムで生成するWebアプリです。
3つのリールが回って止まると、手書き風の感想が入った**アンケート用紙**の画像が開きます。

> 隣の席の方が、雷のような低音を轟かせ、夜も寝られません。

- 3つのリール: 何が → 音や見た目の印象 → どうなったか
- 結果は、アンケート用紙の画像として保存できます（Xへのシェアも可能）
- アンケート用紙の「来場回数」「年代」「満足度」「お名前」は、画面左上の「オプション」で選べます

## 動かし方

ビルドは不要です。`index.html` をブラウザで開くだけで動きます。
（ローカルサーバーで動かす場合の例）

```bash
python -m http.server 8000
# http://localhost:8000/ を開く
```

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | 画面 |
| `style.css` | 見た目 |
| `app.js` | リールの動き、効果音、アンケート用紙（画像）の描画、オプション |
| `reel-data.js` | ネタのデータ（リール3本の文章と、アンケート用紙に載る公演名） |

## ネタを足す

ネタは `reel-data.js` だけを編集すれば足せます。書き方のルールは、そのファイルの冒頭に書いてあります。

## 公開URLの設定

Xへのシェアには、開いているページのURLが自動で入ります。固定したい場合は、`app.js` の冒頭の `APP_URL` にURLを書いてください。

## 補足

- 効果音は、音源ファイルを使わず、ブラウザ内で合成しています。
- フォントは Google Fonts（Shippori Mincho B1、Yomogi）を読み込みます。
